[![website](https://img.shields.io/website?url=https%3A%2F%2Fopenspec.hagicode.com&label=website)](https://openspec.hagicode.com)

OpenSpec Docs is the documentation site for OpenSpec, the spec-driven workflow. Read it at **[openspec.hagicode.com](https://openspec.hagicode.com)**.

## What you can read

- Getting started and installation
- Concepts, workflows and writing specs
- Commands and the CLI
- Customization, supported tools and team workflow
- FAQ, troubleshooting and migration guide

The English documentation tracks a pinned revision of the upstream [`Fission-AI/openspec`](https://github.com/Fission-AI/openspec) repository, so what you read matches a reviewed upstream state. Simplified Chinese topics are reviewed against their English sources.

## Languages

The site is available in ten languages: Simplified Chinese, English, Traditional Chinese, Japanese, Korean, German, French, Spanish, Brazilian Portuguese and Russian. Use the language selector to switch. Where a topic has no translation yet, the site shows the English page with a clearly marked English fallback notice. Translated pages that were produced with AI assistance carry a visible AI-translation notice, so check important details against the English source.

## RSS feeds

Subscribe to be notified of new documentation:

- English: `https://openspec.hagicode.com/rss.xml`
- Other languages: `https://openspec.hagicode.com/rss.<locale>.xml` (for example, `https://openspec.hagicode.com/rss.zh-CN.xml`)

Localized feeds do not include English fallback pages.
